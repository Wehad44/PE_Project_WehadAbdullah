
# IT-Rules-v1_2026_10_15

Responsible-use rules for the Internal IT Help Desk.

**Owner:** Wehad · **Version:** v1 · **Date:** 2026_10_15

Each rule says who, what and when, and can be answered with yes or no.

| # | Area | Rule | Yes / no test |
|---|---|---|---|
| 1 | Data | Before pasting a support ticket, the agent replaces every name, username, email and device code with a code such as User-1, Email-1 or Device-1. | Did I replace all identifying details before pasting? |
| 2 | Verification | Before sending, the agent scores the reply with the five-point verification checklist and sends only a reply that scores 5 out of 5. | Did the reply score 5 out of 5? |
| 3 | Fairness | Before a template enters the library, its owner runs the swap test and records that no unexplained difference remains. | Is the swap-test result recorded? |
| 4 | Policy | The agent uses only AI tools approved by the organization, and the template version and approver are recorded for every reply sent. | Is the tool approved, and are the version and approver recorded? |
| 5 | Human decision | AI never decides access approval, hardware approval or the outcome of a complaint. A person makes these decisions before any reply is sent. | Did a person decide before the reply went out? |
