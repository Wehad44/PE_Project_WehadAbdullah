# IT Help Desk Prompt Library — User Guide

**Version:** v1  
**Date:** 2026-10-15  
**Owner:** Wehad

## 1. Purpose

This library provides reusable prompt templates for common Internal IT Help Desk tasks.

## 2. How to Use the Library

1. Open `library_index.md` to find the appropriate template.
2. Open the selected template in the `templates/` folder.
3. Read the purpose and variable definitions.
4. Replace each required variable with the correct input.
5. Include the approved facts and applicable safety rules.
6. Run the prompt using an approved AI tool.
7. Review the output for accuracy, clarity, safety, and compliance before using it.

## 3. Available Templates

- **Resolve Support Ticket:** Drafts a response to an employee's IT issue.
- **Shorten a Ticket Thread:** Summarizes a long ticket thread for another technician.
- **Explain It Simply:** Rewrites technical information in plain language.
- **Clean a Ticket Before Pasting:** Replaces identifying details with codes before AI use.
- **Fix-it Steps:** Converts a known fix into short, numbered instructions.

## 4. Safety Rules

- Never enter passwords or verification codes into prompts.
- Replace names, usernames, email addresses, and device codes with consistent codes before pasting tickets into AI tools.
- Do not invent facts, troubleshooting steps, or promised outcomes.
- Use only approved AI tools.
- A human must review AI-generated content before it is used.
- Keep sensitive information out of prompts and generated outputs.

## 5. Limitations

- AI-generated responses may be incomplete or incorrect.
- The library does not replace official IT procedures or human judgment.
- If the supplied information is insufficient, ask for clarification instead of inventing an answer.
